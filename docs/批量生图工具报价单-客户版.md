## 交付说明

- 按上述功能范围交付，安装到一台指定的 Windows 电脑，使用一个管理员账号和共享工作区。
- 每个产品包含 10 个图片位置：尺寸图、卖点图、细节图、3 张场景图及 4 张 A+ 图。
- 提供一次远程使用培训和操作说明；验收后提供 30 天上述功能范围内的程序缺陷修复。
- 软件交付费一次收取，不另设强制月费。AI 生图及豆包咨询使用客户自己的服务商账号，实际调用费由客户支付；0 元项不包含第三方调用额度。
- 工作流备份包含产品资料、提示词和图片，不包含 API 密钥及助手对话。
- 新增功能或业务流程变更，另行确认费用和交付时间。

使用实际产品演示资料录入、素材上传、在线工作表粘贴解析、提示词生成、图片生成、历史选图、提示词及已选结果回填和打包下载，并验证 Excel 导出及多个产品进入队列处理。验证豆包咨询的产品及图片上下文、多轮对话、流式回复、停止、失败重试、历史保存及清空。
