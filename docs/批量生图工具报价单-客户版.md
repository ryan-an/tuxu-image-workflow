# 图序 · AI 商品图批量生成系统

## 功能范围与项目报价

**项目交付总价：人民币 6,800 元，一次性费用。**

系统覆盖产品资料与素材管理、整套提示词分析、批量图像生成、后台任务调度、历史版本与选图、在线工作表同步及豆包多模态咨询，形成从资料导入到图片导出的完整工作流程。

**业务流程：** 产品资料与素材导入 → 提示词分析与编辑 → 批量生成与任务调度 → 版本管理与选图 → 工作表回填 → Excel／图片打包导出。

## 二、功能范围明细

### 1. 系统基础与产品素材管理　¥1,200

- **基础框架与工作台设计：** 页面布局、导航、公共交互及产品、表格、队列和咨询模块的流程连接。
- **产品资料管理：** 产品新增、编辑和删除，维护编号、名称、规格、材质及卖点，支持搜索、分页和完成进度展示；删除产品时同步处理关联资料。
- **素材管理：** 管理产品多张实拍图及各图片位置的参考图，支持上传、剪贴板粘贴、预览、切换和移除。
- **参考与结果对照：** 参考图和生成结果并排展示，支持多参考图切换及结果预览。
- **历史版本与选图：** 保留多次生成结果，支持历史版本查看、当前结果选用、下载勾选及状态筛选。

### 2. AI 提示词分析与批量生图　¥2,800

- **产品独立生成要求：** 支持各产品单独设置整套提示词要求，沿用或恢复默认规则。
- **提示词分析与版本管理：** 综合产品资料、实拍及参考图，支持单图片位置及整套提示词分析、流式预览、人工编辑、历史记录及历史提示词恢复。
- **10 个图片位置：** 尺寸图、卖点图、细节图、3 张场景图、4 张 A+ 图。
- **生成与重生成：** 支持单张、整套、多产品批量执行及剩余位置补生成，可对指定位置重新生成。
- **后台任务调度：** 任务排队、并发设置、执行进度、暂停继续，支持单任务或整产品取消，以及单任务、单产品或整批失败任务处理。
- **异常处理与恢复：** 任务错误记录、失败处理及原任务继续查询；服务重启后恢复可继续的任务，平台受理不明确时提示核对。
- **后台持续执行：** 服务保持运行时，关闭网页不影响已提交的后台任务继续处理。
- **原图与批量导出：** 按单产品或整批导出所选图片，支持原图及 ZIP 打包下载。

### 3. 在线工作表与数据同步　¥1,600

- **产品工作表：** 统一呈现产品资料、实拍及参考图、提示词和选定结果，支持分页查看。
- **Excel 导入解析：** 读取支持格式的 XLSX 文件及普通内嵌图片，预览解析结果后确认导入。
- **外部表格粘贴与映射：** 支持外部表格资料粘贴、产品字段与图片位置识别、产品关联及资料更新，并支持待导入新行的整理与删除。
- **工作表结构生成：** 每产品一行资料解析后，补齐参考图、提示词及结果图三行结构。
- **提示词及结果回填：** 提示词分析、图片生成及选用版本变化后，按对应位置更新工作表。
- **编辑保护与冲突处理：** 保留手动修改的单元格；与后台新内容冲突时提示确认，支持保留修改或采用生成内容。
- **模板与 Excel 导出：** 提供产品资料模板导出，支持含资料、提示词及图片的 Excel 导出。

### 4. 豆包多模态咨询助手　¥1,200

- **上下文关联：** 从产品或图片卡片进入咨询时，关联产品资料、提示词、实拍、参考图及生成结果。
- **图文咨询与分析：** 围绕产品图片、参考构图及生成效果进行咨询，获得分析和改进建议。
- **提示词优化建议：** 根据当前图片位置及产品要求，提供可供人工采用的提示词修改建议。
- **多轮对话与流式回复：** 支持连续咨询、逐段输出、主动停止及失败后重试。
- **会话历史管理：** 按产品和卡片保存历史，刷新或重新打开后可继续查看和咨询，支持清空对应记录。
