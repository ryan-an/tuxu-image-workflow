以下金额为本项目的报价建议，不代表市场均价。可复用代码的权利、客户目标电脑和现有接口兼容情况需在成交前核实。本次根据仓库实现整理，尚未针对客户环境进行真实付费接口联调。

## 二、客户实际需要的功能

| 模块 | 交付内容 |
|---|---|
| 产品资料 | 填写产品名称、编号和基础卖点，保存多个产品 |
| 实拍及参考图 | 上传产品实拍图、上传各图片位置参考图，预览和管理素材 |
| 在线产品工作表 | 产品及图片表格展示、外部资料粘贴解析、表格与产品关联、提示词及选图结果回填 |
| 提示词 | 根据资料及参考图生成整套提示词，可手动修改 |
| 批量生图 | 单张生成、整套生成、批量处理待生成位置，查看进度及失败处理 |
| 图片挑选 | 查看历史版本、选择合适的结果、重新生成不满意的图片 |
| 豆包 AI 咨询助手 | 结合产品资料、提示词和图片进行多轮咨询，流式回复及对话历史保存 |
| 下载交付 | 下载所选图片，按产品或整批打包 |

现有流程每个产品固定 10 个图片位置：尺寸图、卖点图、细节图、3 张场景图、4 张 A+ 图。自定义数量和图片角色属于后续改动。

在线产品工作表和豆包 AI 咨询助手单独计价；登录、模型设置、密钥加密、Excel 导出、工作流备份、数据自动保存、浏览器适配和运行日志随工具提供，不另收功能费，详见下方报价明细。

## 四、费用和交付边界

1. 工具交付费一次收取，本方案不另设强制月费。
2. AI 生成和对话费用由客户自己的服务商账号支付，按实际消耗计费，不含在交付价内。
3. 本地电脑运行不需要额外采购云服务器；电脑休眠、关机或应用服务退出时，后台生成会受影响。
4. 多成员权限、支付充值、多店铺管理、ERP 对接、自动发布亚马逊及持续新增功能不在本次范围内。
5. 图片效果受产品素材、提示词及上游模型影响，不能承诺每次生成均达到人工精修效果；尺寸和文字需使用者复核。
6. 源码交付、使用授权及是否独占买断应单独写明；本建议价格未包含独占买断费用。
7. 税费及发票要求在正式报价单中确认。
