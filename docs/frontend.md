# 前端架构与维护

实拍图在工作表中统一置于全部对标图之后，默认预留 6 列，随实际图片数量扩展。旧快照搬移前置实拍图列时保留图片、草稿和自定义行高。解析支持“实拍图1…实拍图8…”及末尾未命名的图片列，按列顺序收集、跳过空白并去重，直接保存到产品 `photos` 列表，`photo` 指向第一张。不新增相册单元格。兼容“2尺寸图”“8A+(1)”等带编号的对标图表头，产品编号优先于序列字段。外部导入缺少实拍图时保留已有图片；在预览中清空全部实拍图则保存为空列表。

页面采用 React 19、TypeScript 和 Vite。Univer 只在打开表格时加载；生成与任务恢复继续使用现有 API。应用不直接调用付费平台。

生产静态文件按请求从构建目录读取，运行中重新构建生成的新哈希资源可立即访问；HTML 入口禁止缓存。构建保留已有哈希资源，供重建前已打开的页面继续加载。缺失的 JS、CSS 等资源返回 404，仅页面地址回退到前端入口，避免把 HTML 当作模块返回。

## 模块职责

界面颜色、标签、状态与按钮使用[界面设计规范](design-system.md)。基础组件与设计变量位于 `src/ui/design-system/`，业务状态标签通过 `ProductStatusBadge` 统一映射；各页面只负责布局，不独立维护状态配色。

| 目录 / 模块        | 负责的内容                                         |
| ------------------ | -------------------------------------------------- |
| `src/ui/products`  | 产品列表、搜索和压缩缩略图                         |
| `src/ui/workbench` | 产品资料、图片位置、结果展示、历史选择、批量操作栏 |
| `src/ui/queue`     | 产品进度、任务明细与操作入口                       |
| `src/ui/dialogs`   | 产品、提示词、历史图、素材、密钥和模型设置弹窗     |
| `src/ui/sheet`     | 稳定的表格挂载容器和解析映射表单                   |
| `src/ui/types.ts`  | 组件所使用的数据、弹窗和控制器接口                 |
| `src/application`  | 业务操作、界面状态、保存、文件和表格协调           |
| `src/services`     | 服务端工作区同步、队列控制、备份素材转换           |
| `src/integrations` | Univer、剪贴板、文件导出与本机存储适配             |
| `src/view-models`  | 产品分页、缩略图与队列展示数据                     |
| `src/demo`         | 演示数据、旧原型与浏览器队列                       |
| `shared`           | 产品、选图和提示词规则                             |

`Application` 负责装配。页面组件只读取上下文，并通过 `ActionButton`、表单或控制器方法发出操作；组件不持有 API Key、不写数据库、不直接触发平台 HTTP。

`src/ui/auth` 提供独立的 `/login`、`/invite#token=…` 页面与成员修改密码弹窗；`src/services/authentication.ts` 调用登录、会话检查、邀请激活和退出接口。会话验证成功后才创建工作台控制器，并将服务端返回的身份传入；退出前保存工作区，卸载时停止轮询与 SSE。密码只在提交时发送，不保存到浏览器存储；Cookie 由服务端管理。演示模式保持原有直接启动方式。

`src/ui/members` 展示当前空间的成员管理；`src/ui/workspaces` 提供左侧产品集合上方的切换入口、内嵌管理页面和新建弹窗。切换列表展示角色、成员数与选中状态，最后一项为“新建工作区”；原生 Popover 保证浮层不被侧栏裁切并支持键盘、Esc 和外部点击关闭。管理页保留侧栏、当前工作区和返回工作台入口，`?manage=1` 刷新后仍打开该视图。`Application` 持有一份 `use-workspaces.ts` 状态，供切换器、`WorkspaceManager` 和 `CreateWorkspaceDialog` 共用，重命名后同步更新侧栏。没有可访问空间时，`WorkspaceHome` 复用同一管理页和弹窗。成员用例由 `use-members.ts` 协调，HTTP 放在 `services/members.ts`、`services/workspaces.ts`。角色按空间生效，后端是权限事实来源。URL 固定本标签的工作区，API 携带 `X-Workspace-Id` 和 `X-Account-Id`，SSE 携带同样的预期身份与空间。切换或新建前等待控制器保存，成功后完整导航，旧表格、队列订阅与助手实例不会复用到新空间。新空间不导入浏览器旧数据，只有默认账号在默认空间仍允许历史数据迁移。查看者不保存工作区，表格只读，下载勾选保存在 UI 状态。

## 状态与生命周期

工作区对象由 `WorkspaceClient` 更新，保留原有字段冲突检测。`state-store` 用新的快照外壳通知 React，订阅通过 `useSyncExternalStore` 接入。界面筛选、弹窗、保存状态和通知独立于工作区数据，不写入业务记录。

表单草稿保留在已挂载的输入组件里。弹窗以本次打开的 key 标识；后台轮询不会更换 key，避免覆盖正在输入的内容。确认保存后才更新业务数据；关闭或 Escape 丢弃尚未提交的表单草稿。模型联动由设置组件的本地状态负责。

顶部操作区显示当前账号和角色、自动保存状态与退出入口；所有者另有「成员管理」和「设置」，除默认部署账号外均可「修改密码」，查看者显示只读状态。保存失败时才显示「重试保存」。密钥、模型、节点和运行方式共用一个设置窗口，密钥清除操作位于对应密钥卡片内；豆包助手中的密钥和模型修复入口也打开该窗口，不再维护独立密钥表单。

执行队列的任务明细通过 `/api/jobs/history` 在服务端查询，按任务创建时间倒序、任务 ID 倒序稳定排序，不按执行状态置顶。搜索和状态筛选在 SQL 中执行，每页 50 条，通过上一页和下一页切换；筛选变化回到第一页，空页自动收敛到最后有效页。该接口独立于用于工作台任务状态与产品汇总的工作区同步。

「设置」按钮内根据服务端返回的密钥配置状态显示提示：豆包和 Grsai 密钥均已保存时显示绿色圆点和「已填 API Key」；缺失时显示红色圆点并列出未设置的服务名称。保存或清除密钥后立即更新，移动端保留可见。该提示只表示已填写，不代表平台验证通过。

顶部数据保存成功后显示绿色小圆点和「已保存数据」；保存中或保存失败时移除绿点，继续展示对应状态。

产品资料与「整套提示词要求」共用一条左右布局的资料栏，长资料最多显示两行，完整内容可在产品编辑窗口查看。带图标和数量的实拍图按钮在窄屏也保持可见；要求区显示默认／自定义状态，正文在编辑窗口查看。布局根据资料栏实际宽度在窄屏改为上下排列。编辑弹窗固定绑定打开时的产品 ID，保留完整自由文本域，支持放大、字面查找替换及一步撤销。`requirement-drafts` 按账号、工作区和产品保留本机草稿；关闭和刷新后恢复，成功保存或恢复已保存内容时清除。模板按 ID 存在工作区 `promptTemplates` 中，只提供可复用的文本来源，套用和保存模板均不提交产品要求；模板支持名称、正文更新、另存和删除。应用层 `requirements` 通过客户端 `edit` 提交打开时冻结的旧值，冲突保留文本并刷新已保存资料，不覆盖其他本地编辑。`product.promptRequirements` 为产品独立覆盖值，未设置时沿用工作区原有 `common`，兼容旧产品和备份。整套分析及单卡分析在入队时保存该产品的实际要求，后续修改不改变已排队任务；豆包咨询也读取当前产品的实际要求。自定义要求不依赖四段标题解析，整套分析的返回协议保持不变。

要求编辑窗口使用受视口约束的 flex 外壳，标题、模板工具、状态操作均保持紧凑单行；只有文本域内部滚动，弹窗外层不滚动。模板命名浮层不推挤正文。全屏模式铺满视口，隐藏产品与模板、普通状态底栏，保留查找、退出和保存；Esc优先关闭查找或退出全屏，Ctrl+S保存当前产品要求。操作采用共用 `Button size="sm"` 的主次、辅助及危险变体，正文与辅助文案使用不同的颜色层级。具体审查约束见 `docs/design-system.md`，浏览器回归检查实际尺寸、对比度、溢出和全屏状态。

产品、图片位置和历史版本以业务 ID 作为列表 key。没有整页 `innerHTML` 渲染，也不需要重绘后手工恢复光标、滚动和 details 展开状态。

表格面板始终保留挂载容器，视图切换使用 hidden；Univer 对自己的容器负责。应用卸载时释放表格、轮询、事件监听和定时器。拖拽、剪贴板事件只保留在 `browser-events` 适配器中，不承担普通按钮与表单分发。

上传在异步读取之前冻结产品和图片位置 ID，按顺序追加；关闭弹窗或切换产品不会改变已经开始读取的目标。图片下载同时支持 data URL 与服务端素材 URL，ZIP 保存实际图片内容。

在线表格图片粘贴最多并行读取 6 张，同一次粘贴的重复链接共享下载，按原始单元格位置写入，单张失败不阻塞其他图片。解析确认、启动时核对与后台回填使用 `SheetBridge.batch`，一次提交稀疏单元格矩阵，并在批次边界获取快照；合并单元格和回填位置使用索引，未变化的单元格跳过写入。服务端在单次请求内复用重复图片的落盘结果。

提示词完成、图片完成与选定版本切换时按变化位置回填，并保存工作表快照。单元格只有文字、图片原始地址或公式实际改变才记录 `workflowDrafts`，格式调整、重复粘贴、点击进入编辑不会产生草稿；改回原值会清除该位置的草稿。保护范围仅为该单元格，产品行使用稳定产品 ID 绑定。旧的整行草稿标记迁移为内容差异，重复空白提示词／结果行不会覆盖有效行。

确认「保存并解析」时，当前解析产品在工作流预览中统一整理为「示例图、提示词、结果图」三行，缺行自动补齐，编号、状态、名称／资料各自纵向合并。未提供的提示词／结果行不视为清空工作区已有内容，补齐后回填已有内容，不启动生成任务。行位置变化时同步保留后续产品、合并区域、草稿、自定义列和行高；重复解析不会重复插入。不同名称／资料或重复内容行无法安全合并时明确提示并保留原表。

后台内容与手动修改同时变化时保留手动值，工作表上方持续展示产品、图片位置、内容类型和单元格坐标。用户可以采用最新生成内容，或保留表格修改并确认当前后台版本；再次发生后台变化时重新提示。草稿与原值随快照持久化，重新打开会核对并恢复尚未解决的冲突；确认解析才将表格修改应用到产品工作区。

图片卡片并排提供等大的 1:1 参考图与结果图区域，图片使用 contain 完整显示，多张参考图可切换。提示词独立展示，点击文字或空态可就地编辑；尚未修改的编辑框在生成开始或新提示词到达时恢复预览，避免空白草稿遮挡生成结果。用户输入或主动清空后，草稿由组件持有，轮询与流式文本不覆盖正在编辑的内容。保存通过控制器协调提示词历史、表格回填和服务端持久化，取消只丢弃当前编辑草稿。

生图时结果区域展示图片叠层浮动、扫描微光动画和进度条，区分排队、暂停、提示词准备、提交和平台生成。百分比读取当前卡片最新生图任务的服务端 `progress`；没有有效平台进度时采用等待动画，不推算百分比。重新生成时在原结果上显示新版本进度，任务完成、失败、取消或中断后移除加载层；动画遵从系统减少动态效果设置。

提示词就绪时卡片标题左侧圆点为绿色。顶部整套提示词按钮跟随任务状态，生成中显示转圈图标与「生成整套提示词中，点击终止」，点击原按钮终止当前产品排队或执行中的提示词任务，不另设分析取消按钮。生成操作使用分体式按钮，右侧下拉选择生成提示词、使用现有提示词生图或执行完整工作流；完整工作流重新生成整套提示词后再执行依赖生图，底部仅保留下载按钮。

普通操作在 `commands` 中协调，表单提交在 `form-commands` 中协调；表单的防重复提交和输入草稿归组件负责。

## 修改方式与验证

增加页面交互时：先确定数据规则属于 shared、应用操作还是 UI 草稿，再添加控制器方法和组件。新弹窗在 `DialogHost` 注册；不要重新引入 HTML 字符串模板或 document 上的点击 / 提交监听。

`npm run typecheck` 检查后端和新前端组件；`npm run build` 强制先执行类型检查。业务适配模块和旧共享 JavaScript 仍沿用现有测试，尚未全部转换成 TypeScript。

`npm test` 验证业务与服务端恢复。可选 Chrome 回归验证真实 DOM、后台刷新时的提示词和设置草稿、表格实例复用、解析映射展开状态、版本勾选、素材 ZIP 内容及备份。执行方式见 README，使用隔离数据库和模拟平台，不产生付费调用。

### 大工作区分页与同步

产品集合和产品工作表共享分页状态，每页固定 30 个产品，搜索覆盖全部产品并回到第一页；切页选择该页首个产品。左侧列表采用固定行高虚拟滚动和预渲染缓冲，手机端使用当前页产品选择器。

工作表仅将当前页投影挂载到 Univer，保留完整工作簿作为原始坐标数据。切页先捕获当前页编辑；跨页任务回填写入原始坐标，全量 Excel 导出和备份继续使用完整快照。分页预览禁止插入、删除、移动行列等会破坏坐标映射的结构操作；新产品通过产品集合添加，外部批量资料通过「外部粘贴」导入。

首次进入仍读取完整工作区以兼容队列、备份和跨页编辑，此后 `/api/workspace/changes?since=…` 按数据库修订号返回变化实体与删除标记。SQLite 触发器在原事务中维护每个实体的最后修订号，事务回滚不产生可见变更，空闲轮询不传输产品、任务或表格数据，也不重新渲染。失效游标自动重新读取完整工作区；多次并发刷新合并为一个请求。

存在排队或运行中的任务时，增量同步间隔为 2.5 秒；空闲时为 20 秒。页面隐藏时暂停轮询和分析事件触发的刷新，恢复可见时立即同步；已发出的请求允许完成，但不会在隐藏时重新启动计时器。主动刷新后也会根据最新任务状态调整间隔。后端游标与当前修订号一致时，只查询修订号便返回空增量，跳过实体查询。

生产图片预览使用鉴权的 `/api/assets/:id/thumbnail`，最大 320×320，WebP 编码、磁盘缓存、相同图片请求合并、最多 3 个并发解码。左侧图片通过浏览器懒加载；当前页表格只引用缩略图，捕获、解析、导出恢复原始图片地址。缩略图不替换原始资产，不影响生成与原图下载。

大工作区仍会在首次加载、备份、全量导出和兼容性的编辑保存时处理完整数据；这些优化不代表任意规模下恒定内存。新增测试覆盖 1000 产品的分页、跨页回填、草稿保留、游标、鉴权缩略图和真实浏览器交互；不等同于 1000 产品包含所有真实大图和历史版本的长期压力测试。

顶部提供小尺寸的「操作历史」入口，在右侧悬浮抽屉中只展示当前工作区最近 100 条记录，按日期分组、保存顺序从上到下排列，打开时滚动到底部最新记录。点击日志可查看修改前后文本或图片，底栏提供「回到最新」；标题和底栏固定，仅日志正文滚动。支持窄屏、空状态、读取失败重试、点击外部与 Esc 关闭，不提供冲突确认或逐字段恢复流程。显示数量限制不删除数据库中的旧记录。

编辑者的表格选区通过独立协作通道广播，使用当前账号名称和稳定颜色；选区坐标映射到完整表格，跨产品分页时只显示当前页对应范围。单元格提交后自动保存并推送，仍需「保存并解析」才将表格草稿转换为产品资料。普通远端单元格变化就地写入，不重建表格或替换当前选区；结构变化才重建投影。系统写入不触发用户自动保存，也不进入撤销记录。

测试统一存放在 `tests/`，不得与业务源码混放；单测、集成和浏览器回归入口见 [测试目录约定](../tests/README.md)。
