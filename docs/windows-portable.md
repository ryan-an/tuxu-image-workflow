# 图序 Windows 便携部署包

适用于 Windows 10/11 x64。内置 Node.js 24、SQLite 及运行依赖，无需安装 Node.js、Docker、数据库或执行 npm install。服务器仍需联网访问豆包和 Grsai；其他局域网电脑只需浏览器。

启动器和更新器使用与平台一致的浅色卡片、蓝紫按钮和状态配色，可复制访问地址、打开数据目录。界面使用开源 [AntdUI](https://github.com/AntdUI/AntdUI)（Apache-2.0），组件内嵌于 EXE，使用时无需另行下载；完整许可随包放在 `runtime/licenses/` 目录。

## 数据迁移约定

便携版固定使用程序目录旁的 `data/` 和 `.env` 作为唯一迁移边界：

```text
图序目录/
├─ 图序.exe 或 启动图序.cmd
├─ data/        # SQLite、WAL/SHM、素材、日志、HTTPS 证书
└─ .env         # 登录密码、加密主密钥、运行配置
```

升级或更换 ZIP、EXE、安装程序时，先停止旧版本，完整复制 `data/` 和 `.env`，再放入新版程序目录。不要只复制 `workspace.sqlite`，也不要修改或删除 `CREDENTIAL_SECRET`。默认配置不把业务数据写到 AppData、Temp、注册表或程序外部目录。

只有在管理员主动修改 `.env` 的 `DATABASE_PATH`、`ASSET_DIRECTORY` 或证书路径时，才会产生额外迁移目录；此时这些路径也必须一并备份。未保存的浏览器草稿属于浏览器本地数据，不在服务端迁移范围内。

1. 将 ZIP 完整解压到本地可写目录，例如 D:\Tuxu。不要在压缩包内直接双击，也不要放在系统保护目录、网络共享或同步盘上运行。
2. 双击带紫色图片图标的“图序.exe”，打开精简服务窗口，不弹命令行窗口。主界面默认显示可复制的局域网地址，「打开工作台」及托盘中的同名入口也使用该地址；没有可用局域网地址时回退到本机地址。多个网卡时默认使用第一个候选地址，其余可在「局域网访问」菜单复制。「更多」内可查看日志、打开数据目录。首次启动自动创建独立的 .env 和空数据目录，额外显示 admin 的初始密码，可显示或复制；后续不会重新生成。EXE 需与 runtime、scripts 和程序文件放在一起，不能单独复制运行；原 CMD 仅保留用于手动排查。
3. 本机浏览器打开 http://127.0.0.1:3001，登录后在设置中填写平台 API Key。
4. 局域网使用时，将可信办公网络设为 Windows 专用网络，点击「局域网访问 → 允许局域网访问」并允许 Windows 管理员授权。此操作只放行专用网络本地子网访问当前服务端口，不弹命令行窗口。「局域网访问」菜单列出候选地址，点击即可复制给同事；多个网卡时选择办公网对应地址。无需路由器端口映射。
5. 在路由器为服务器保留固定 IP，并关闭服务器自动睡眠。在成员管理中邀请同事，不要共用管理员账号；邀请链接请从局域网地址创建。

后台运行：关闭或最小化服务窗口，只隐藏到 Windows 右下角通知区域，任务和局域网访问继续运行；图序图标可能在「显示隐藏的图标」中。双击托盘图标可恢复窗口，右键可打开工作台、显示窗口或查看日志。同一目录重复打开图序.exe 会唤回已有窗口。

停止：在托盘图标右键菜单或窗口「更多」中选择「退出图序并停止服务」；程序等待后台关闭数据库后退出，托盘图标随之消失。备份、迁移及更新前必须执行此退出操作，仅叉掉窗口不会停止服务。

密码：编辑 .env 中 APP_PASSWORD 后重启。CREDENTIAL_SECRET 是加密主密钥，必须保留，不能随意修改。不要分享 .env。日志在 data/logs/server.log，初始密码不会写入该日志。

备份：停止服务后复制完整 data 目录和 .env 到另一存储位置，再重新启动。不要运行中仅复制 workspace.sqlite 文件。

日常更新：保存编辑，从托盘菜单选择「退出图序并停止服务」，运行新版 `tuxu-update-windows-x64-v版本号.exe`，选择原程序目录并点击「开始更新」。更新进度和结果显示在窗口中，不弹命令行窗口。工具先备份数据和配置，再替换程序，保留原 data 与 .env；完成后启动图序即可。完整步骤和恢复方法见 [Windows 更新说明](windows-update.md)，部署包内也附带「更新说明.md」。

手动升级：也可先停止旧服务并备份，把新版解压到新的目录，再将旧目录完整 data 和 .env 复制到新目录，然后启动新版。不要同时运行两份程序操作同一数据。数据库可能执行追加迁移；回退时使用升级前的完整备份。

HTTP 可用于可信局域网，但传输不加密；部分浏览器剪贴板按钮可能受限，可改用 Ctrl+V 或文件上传。需要 HTTPS 时须另外配置证书并在客户端信任。此包不自动设置开机启动或修改系统网络配置。

此包不包含开发电脑的业务数据、账号、平台密钥或配置。Windows ARM64 和 Windows Server 未在本包目标环境中验证。

维护者打包：在 Windows x64 Node.js 24 下安装依赖，运行 npm test、npm run build，然后 npm run windows:pack。打包使用 Windows 自带 .NET Framework C# 编译器生成带图标的启动入口，并从 public/tuxu.svg 生成多尺寸 ICO；不额外安装打包工具。输出在 artifacts/windows，包含 ZIP 和 SHA256 校验文件。

桌面界面颜色与圆角由 `src/ui/design-system/tokens.css` 生成，和平台共用唯一来源。AntdUI 版本及 SHA256 固定在 `scripts/windows/desktop-ui.lock.json`，首次打包会从 NuGet 官方源下载并校验；后续使用本地构建缓存。桌面依赖与其许可内嵌于启动及更新 EXE，构建缓存不写入部署包。
