# 图序 · 批量生图工作流

本地独立网页：产品与任务在主应用管理，Univer 表格用于外部数据粘贴、解析导入和结果预览。默认准备 30 套演示产品，每套 10 个图片位置。演示模式的图片由本地绘制，不调用付费生图服务。

## 使用

1. 在左侧打开产品，编辑产品资料或上传多张实拍图。按固定顺序为10个位置提供对标图，点击产品资料旁的「生成整套10张提示词」：每个产品只分析一次整套对标图，先确定统一设计规范，再回填全部10条提示词。图片卡片仅显示小参考图、大结果图和横向历史列表；点击「提示词」在弹窗中编辑，保存后用于下一次生成并回填表格，取消不修改。历史提示词在同一弹窗中展开查看和恢复。结果图可点击放大，卡片内可单独生成图片和重试。
2. 左侧列表只用于切换产品，没有批量选择。工作台也没有生图位置勾选：「生成整套提示词」始终一次分析当前产品全部10张对标图；「生成本套10张图片」使用已填写的整套提示词；「执行本套流程」在提示词缺失时先分析整套，再生成本套10张图片。整套分析失败不会继续提交这些图片。任务不受历史图片勾选或工作台筛选影响。跨产品处理使用执行队列的「批量生成剩余」，30套最多是30个整套分析任务加300个生图任务。队列支持1–6个并发任务、暂停排队、停止等待、失败重试。
3. 生成和重试始终保留历史。点击历史缩略图直接选为表格展示并加入本套 ZIP 下载，不打开弹窗，同时取消同一图片位置其他历史版本的下载勾选；每个位置最多勾选一个版本。直接勾选也会选为展示版本，取消勾选仅取消下载，保留表格展示。底部「下载本套选中图片」只打包当前产品。大结果图可点击放大。首次生成默认选为表格展示版本，重试不会覆盖已有展示或下载选择。
4. 「表格预览 / 导入」含「工作流预览」和「外部粘贴」，没有产品总览表。每个产品默认三行：示例图、提示词、结果图；产品编号及产品名称 / 资料分别纵向合并这三行，每种图片类型占一列。已有预览表会自动合并重复的产品信息，保留单独编辑的不同内容和已有合并。主应用自动回填提示词与选中的展示结果。通过合并格里的编号、行类型和图片类型表头重新定位，插入行列后仍可回填；删除这些标识则会明确提示回填失败，应用结果不丢失。
5. 外部表格粘贴到「外部粘贴」后，点击「解析到应用」，检查布局和列映射，再确认导入。支持每行一个产品、每个产品三行、无表头图片行。相同编号更新参考图和提示词，保留生成历史。文本、HTML 表格图片、石墨临时图片链接、Markdown 图片链接表格和图片文件均可粘贴。文字与图片保留空列、空行及跨行合并格所占的位置，避免图片错列；导入内容不复制原表的合并样式。
6. 「导出 Excel」保存当前表格的内容、基本样式、公式和嵌入图片。Excel 图片以浮动图片锚定在对应单元格位置，尚未采用新版原生单元格内图片；复杂专有样式、批注、条件格式与浮动图形暂未导出。

「执行队列」按产品汇总，每套一行显示生成进度、历史图数量、已选数量和状态。点击「查看 / 选图」进入该产品的历史版本；「批量生成剩余」只补尚无结果的位置；「重试失败任务」恢复失败的任务；「保存整批选中图片」下载所有产品勾选的历史版本，不受左侧产品勾选限制。下方可展开任务明细，设置并发或停止任务。暂停仅停止继续派发，运行中的任务仍会完成。

产品列表及队列使用第一张实拍图的独立 WebP 缩略图，最长边不超过96像素、每张不超过12KB。上传、导入或更换实拍图后在后台逐张压缩，避免同时解码大量原图；缩略图和原图指纹保存到本机，刷新复用，原始实拍图不修改。图片标签使用固定尺寸、延迟加载和异步解码；没有实拍图时显示占位符，不使用全尺寸图片替代。

点击产品实拍缩略图、「实拍图」或任意卡片的参考图，打开统一的图片添加窗口。支持选择多张图片文件、Ctrl+V粘贴截图或复制的图片、读取剪贴板按钮，以及石墨图片单元格 / 图片链接粘贴。也可直接把文件拖到实拍或参考缩略图上。默认追加，按图片内容跳过重复项；「替换全部」通过文件选择显式替换当前组。添加后保留窗口，方便继续粘贴、查看和移除，自动保存，不启动生成任务。剪贴板读取被浏览器拒绝时提示使用Ctrl+V；无效图片或失效链接显示错误并保留已有图片。异步添加固定到开始时的目标，切换产品不会错放到新产品。

## 四部分提示词

「整套共用要求」全部是提示词分析规则，仅发送给分析模型，不直接发送到生图接口。全文都能编辑，包括第三部分产品规则、文案语言与字数、品牌、尺寸及分辨率。修改后用于下一次整套分析，已生成的提示词和历史图片保留。

默认第一部分要求重新安排各张布局、改写贴合产品的英文文案，尺寸图包含提供的尺寸和数量，A+1包含提供的品牌；第二部分要求整套统一配色、字体字号、横幅和边框；第三部分按用户当前正文原样保留；第四部分默认前六张1610X1610像素、后四张970X600像素、分辨率300，可在编辑框修改。程序不再强制追加旧的产品规则或旧尺寸。

模型一次返回完整10张结构化结果，不进行缺失角色的部分回填。文案校验依用户当前规则判断：默认英文、合计5–10词、尺寸图包含尺寸与数量、A+1包含品牌；相应规则修改后按新规则处理。产品信息读取顶部资料，示例中的25个装、24×28cm、Blcculi不硬编码到其他产品。对标图只发送给提示词分析模型；实际生图仅发送各张生成后的提示词及选定实拍图，不带共用分析要求。支持多张实拍图和由分析模型选择视角。

演示模式仍是本地示例布局，未进行真实视觉识别。演示字体示例使用[Inter官方字体](https://rsms.me/inter/)，其许可为SIL OFL 1.1；真实模式按分析模型返回的设计规范生成。像素与分辨率要求写入提示词，最终平台输出的像素及DPI仍取决于其模型与设置，不保证仅靠文字强制输出尺寸。

## Grsai 设置

右上角「密钥设置」是独立的小入口，可保存、替换和清除 API Key。密钥只保存在本地服务内存中，不写入浏览器、表格或工作流备份；开发模块刷新保留密钥，重启服务进程后需重填。保存密钥不自动启动任务。「模型设置」提供分析模型和生图模型的下拉选择，分析模型也支持自定义名称；还可配置国内 / 全球节点、比例、尺寸和质量。旁边的运行方式按钮可选择演示或真实生成。

实现依据用户提供的 [nano-banana 文档](https://qmy27nhsd9.apifox.cn/452392911e0)、[GPT 生图文档](https://qmy27nhsd9.apifox.cn/452409160e0)和[结果查询文档](https://qmy27nhsd9.apifox.cn/452409577e0)。nano 系列发送比例与 imageSize；GPT 系列发送尺寸与 quality。参考图和实拍图随请求传入。提示词分析使用同平台的 chat/completions，默认 gemini-3.1-pro，可修改。

生图使用异步提交与轮询。收到平台任务 ID 后立即保存，刷新恢复时继续查询该任务，不重新提交。停止仅终止本地等待，平台已受理的任务可能继续执行。若关闭页面时尚未拿到平台 ID，无法自动恢复该未知任务，需要到平台检查。

图片比例、分辨率以及 GPT 尺寸 / 比例默认均为 auto，可手动修改。nano 的比例 auto 直接交给平台；分辨率 auto 表示不指定 imageSize，沿用模型默认。Grsai 的[官方 nano 文档](https://grsai.com/zh/dashboard/documents/nano-banana)说明 imageSize 为选填，枚举1K、2K、4K，默认1K，因此不直接传入未列出的字符串 auto。旧工作区中原默认1:1、1K、1024x1024会一次性升级为auto，其他手动值保留；升级后手动设置这些值仍会保存。已排队任务保留原提交配置。

## 保存与部署

工作流、全部历史、勾选和表格自动保存到本机浏览器 IndexedDB；也可手动保存。表格工具栏提供整个工作流 JSON 备份与恢复，备份含历史图片。原 demo 的保存键保留不删除，新工作区会迁移已有产品资料与两套参考图。

前端资源由本机提供。石墨图片通过本地图片服务读取，已限制到石墨图片域名及其图片 CDN，不上传给 Univer。选择真实生成时，产品资料和参考图发送给 Grsai。当前为单机应用，未加入账户、多人协作或云端存储。

需要 Node.js 20.19+ 或 22.12+。在本目录运行 `npm install`，然后 `npm run dev`，打开 http://127.0.0.1:5173/。`npm run build` 构建，`npm run preview` 可本地运行构建后的网页与接口。正式服务器部署还需部署本地接口与自己的身份验证；单独托管静态文件无法调用本地代理。

## 验证

接口参数、整套响应校验及队列依赖测试：`npm test`，覆盖每套只分析一次、分析完成后才生图、分析失败阻止生图、重试恢复、执行期间编辑保留，以及全部规则可编辑。此测试使用隔离的假服务，不调用付费平台。`verify-suite.cjs`从网页验证整套生成、编辑规则、四部分提示词、十格回填、实拍图选择及刷新保存。

本开发环境的浏览器检查使用现有 Playwright 运行时和本机 Chrome：`verify-workflow.cjs`（历史、选择、三行回填与刷新）、`verify-import-batch.cjs`（三图粘贴、解析、插入行列及 30 × 10 批量）、`verify-clipboard-grid.cjs`（合并格位置、空行列、Markdown 与原生单元格图片）、`verify-resume.cjs`（平台 ID 自动落盘、只提交一次并恢复查询）、`verify-delivery.cjs`（密钥入口、模型选项、Excel、ZIP、备份恢复）。它们用独立浏览器上下文和模拟接口，不修改用户工作区或调用真实付费生成。

`verify-queue-design.cjs` 验证30套产品的队列汇总、选图跳转、失败重试、补齐剩余、整批下载、模型下拉选择及自定义模型。接口测试同时验证开发模块刷新保留密钥且不返回密钥正文。

`verify-merged-metadata.cjs` 验证已有产品信息三行合并、新增产品、合并表格解析、插入行列后的回填、刷新保存，以及 Excel 导出保留合并。

`verify-product-sidebar.cjs` 验证产品列表和图片位置不出现勾选框、上传大尺寸照片后的实际缩略图尺寸及字节上限、原图保留、列表与队列仅使用压缩图，以及刷新后不重新编码。

`verify-current-product.cjs` 验证点击历史图直接展示并勾选下载、同一位置只勾选一个版本、取消勾选保留展示、下载不包含其他产品勾选的历史图、不需要勾选即可整套生成提示词，以及本套生图始终处理10个位置。

`verify-compact-cards.cjs` 验证卡片紧凑布局、不同窗口宽度下的列数、提示词弹窗保存 / 取消 / 历史恢复、后台更新保留编辑草稿、表格回填、重试保留选图和下载勾选，以及刷新保存。

`verify-media-upload.cjs` 使用隔离浏览器和模拟剪贴板验证图片粘贴、拖拽、文件追加 / 替换、重复跳过、石墨图片组、失败保留原图、异步目标定位、表格回填及刷新保存，不读取或修改用户剪贴板。

已验证上述流程和构建；真实平台的账户权限、额度及模型输出仍需填入密钥后验证。
