# Grsai 图片限制与错误说明

核对日期：2026-11-10（北京时间）。

## 限制的核对结果

官方 [GPT Image 新版接口](https://qmy27nhsd9.apifox.cn/452409160e0)、[Nano Banana 新版接口](https://qmy27nhsd9.apifox.cn/452392911e0)允许参考图使用 Base64 或 URL。核对其公开 Markdown 参数表和旧版说明后，未找到单张图片或整个请求统一限制为 6MB 的明确条款；不能把应用自己的阈值称为官方上限。平台、节点或前置代理的实际限制仍可能不同。

[HTTP 413 的标准语义](https://www.rfc-editor.org/rfc/rfc9110.html#name-413-content-too-large)是请求内容超过接收方可接受的大小，不足以证明某张原始图片超过 6MB。Base64 长度为 `4 × ceil(文件字节数 / 3)`，还需加上图片前缀、JSON、提示词及其他参数；多图的大小需要合计。

上传时仅对大于 6×1024×1024 字节的新文件压缩，小于或等于该值的原文件不重编码。旧素材、平台生成图片及远端 URL 原先不受这条上传规则重新处理，因此此前的单张规则无法保证生图请求总大小。

现在发送生图请求前，应用按完整 JSON 的实际 UTF-8 字节数，采用严格小于 6,000,000 字节的保守预算。只有总量超限时才压缩较大的内嵌图片；保留每张附图、顺序、比例与透明背景，先降编码质量再按需缩小尺寸，不修改已保存的素材、提示词、任务冻结输入或历史结果。URL 仍按链接发送，此预算不等于已校验远端图片文件的实际大小。最终超限或文字本身超限时不提交平台，也不因 413 自动重新提交付费请求。

## 中文错误映射

官方旧版 [GPT Image](https://grsai.ai/zh/documents/gpt-image)和 [Nano Banana](https://grsai.ai/zh/documents/nano-banana)文档列出以下失败原因。新版接口文档主要提供 `error` 文本和任务状态，没有完整的错误码中文目录。

| 原始值 | 来源 | 页面说明 |
| --- | --- | --- |
| `input_moderation` | 官方失败原因 | 提示词或参考图片未通过平台审核 |
| `output_moderation` | 官方失败原因 | 生成图片未通过平台审核 |
| `error` | 官方失败原因 | 平台生成失败，可稍后重试 |
| `generate failed` | 新版官方错误示例 | 平台未能生成图片 |
| `Invalid input parameters` | 旧版官方错误示例 | 生图参数不符合平台要求 |
| `-22` | 旧版结果查询说明 | 平台找不到任务，可能已超过查询有效期 |
| `generate image failed` | 已观察的平台原文，应用翻译 | 平台未能生成图片 |
| `server_timeout` | 已观察的平台原文，应用翻译 | 平台生图处理超时 |
| `violation` | 新版官方任务状态 | 内容未通过审核，无法由此确定是输入还是输出 |

官方[异步结果查询文档](https://qmy27nhsd9.apifox.cn/452409577e0)说明最终结果的任务查询有效期为 2 小时；找不到任务不能一概认定为过期。

`result not exist, valid for 2 hours` 表示查询接口暂未找到结果，不能据此认定刚提交的任务已经过期。应用对此类明确结果缺失响应和旧版 `-22` 结果错误使用原 ID 退避重查，连续最多 5 次；期间不重新提交生图，查询恢复正常则清除旧错误。持续失败后，用户点击“重新生成”才创建新任务，保留原 ID 和错误记录；已有历史错误按保留的原文识别，无需批量改写。普通接口 404、权限、审核与下载错误不因此自动创建新任务。

HTTP 状态按标准语义提供应用中文解释：400／422 参数无法处理、401 密钥无效、402 计费状态、403 权限不足、404 接口或任务不存在、408 超时、413 总数据量超限、415 格式不支持、429 请求过频或服务繁忙、500 内部错误、502 上游或网关异常、503 暂不可用、504 上游响应超时。这些是应用解释，不伪装成 Grsai 官方中文错误码表；已有明确中文原因时优先保留。

新错误以中文解释为主，同时保留经过密钥隐藏的原始错误、错误码及请求／任务标识；不展示代理 HTML，也不把未知错误猜测成余额不足或模型维护。豆包错误继续走原有处理。已保存的历史错误不批量改写。
