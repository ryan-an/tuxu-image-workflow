# 图序 v0.2.13 更新说明

版本日期：2026-11-13。

- 整套提示词要求编辑窗口恢复上次光标、选区和滚动位置，关闭重开、保存和刷新后都可继续编辑；账号、工作区、产品和模板分别记忆，位置保存在当前浏览器。
- 产品集合按创建时间倒序显示，编辑资料或生成图片不改变产品排序。
- 选图下载按固定位置编号：2 为尺寸图，3 为卖点图，4 为细节图，5—7 为场景 1—3，8—11 为 A+ 1—4；未选位置跳过，后续编号不递补。

已有 Windows 程序使用 `tuxu-update-windows-x64-v0.2.13.exe` 更新；首次安装使用 `tuxu-windows-x64-v0.2.13.zip` 完整便携包。两个文件均附 SHA256 校验文件。

升级前保存编辑并等待任务结束，从托盘退出并停止服务，运行更新 EXE，选择原程序目录。完成后重启并刷新页面。保留 `data`、`.env` 和 `CREDENTIAL_SECRET`。相对 v0.2.12 无新增数据库迁移。详细步骤见 [Windows 更新说明](../windows-update.md)。
