# 图序 v0.2.4 更新说明

发布日期：2026-10-28。

## 本次更新

- 修复 Windows 更新器仍要求旧版「第三方许可」目录，导致更新包无法安装的问题；组件声明继续保存在 `runtime/licenses/`。
- 修复旧数据库因 Windows / Linux 换行格式不同而误报“已执行迁移 001.sql 内容发生变化”的启动问题，保留已有迁移记录；真实 SQL 内容不一致仍会停止升级并显示具体原因。
- 构建时移除残留迁移文件并统一换行格式，避免旧构建文件混入更新包。
- 工作区的对话模型、运行方式及生图节点由所有者统一管理；成员的生图模型、比例、分辨率和尺寸质量各自保存。API Key 继续由所有者管理。

## 升级说明

1. 保存编辑并等待任务结束，从图序窗口「更多」或托盘菜单选择「退出图序并停止服务」。
2. 运行 `tuxu-update-windows-x64-v0.2.4.exe`，选择原程序目录后开始更新。已装 v0.2.3 的用户也使用此包升级。
3. 保留原 `data/`、`.env` 和 `CREDENTIAL_SECRET`，不要删除数据库或手动修改迁移记录。
4. 更新完成后启动原目录的图序，刷新浏览器，确认工作台显示 **v0.2.4**。

本次修复不新增数据库迁移；从更早版本升级时会执行尚未应用的迁移。更新前工具会备份数据与配置，成功快照合计保留最近 2 份，重要备份请另存到其他设备。完整步骤见 [Windows 更新说明](../windows-update.md)。
