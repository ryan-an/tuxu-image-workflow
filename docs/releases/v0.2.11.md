# 图序 v0.2.11 更新说明

版本日期：2026-11-10。

## 本次更新

- 生图默认使用 `gpt-image-2`。已有工作区和成员保存的生图型号在首次升级启动时统一初始化一次，质量设为 `auto`，保留原有尺寸设置；升级后重新选择的模型和参数在后续重启时保留。
- 生图失败可直接重试，移除平台核对入口。取得有效平台任务 ID 后立即保存，后续查询和重启继续沿用该 ID；没有取得 ID 的异常请求显示失败。
- 生图发送前按全部附图、提示词和参数的实际传输总量检查，计入图片编码增加的体积，按需压缩发送副本并保留附图顺序；原始素材和历史图片不变。无法容纳时在提交前给出中文提示。
- 常见审核、生成失败、超时和 HTTP 错误增加中文解释，保留平台原始错误及错误码、请求或任务标识。
- 整套提示词要求默认留空，先填写要求或选择模板并保存后再分析。保存、更新或另存模板时，同时保存当前产品的要求和来源绑定。
- 手写要求和各模板的编辑草稿分别保留，切换、关闭重开或刷新后可继续；切回“未选择模板”恢复原手写草稿，原本为空时保持空白。
- 模型配置、模板、成员角色、队列筛选和表格映射等下拉选择统一样式。支持的浏览器使用白色菜单与紫色选中反馈，其他浏览器保留原生菜单；选择值和分组保留。
- 修复更新工具在检查运行中程序时可能出现的空引用错误，继续阻止覆盖正在运行的图序。

## 升级说明

1. 保存网页上的编辑，等待正在生成的任务结束。尚未保存的草稿请先另行留存。
2. 从图序窗口“更多”或托盘菜单选择“退出图序并停止服务”。关闭窗口只会隐藏到托盘。
3. 运行 `tuxu-update-windows-x64-v0.2.11.exe`，选择原程序目录后开始更新。保留原 `data/`、`.env` 和 `CREDENTIAL_SECRET`。
4. 更新完成后重新启动图序并刷新页面，在“账号菜单 → 更新日志”确认显示 **v0.2.11**。
5. 首次启动执行一次性生图配置迁移，将所有已有工作区（含归档工作区）和成员保存的生图型号设为 `gpt-image-2`、质量设为 `auto`。其他尺寸参数、密钥、豆包配置、历史图片及已排队任务的模型快照保留。
6. 旧中断任务有平台 ID 时恢复查询，没有 ID 时转为可重试失败，保留任务记录与已生成图片。重试没有 ID 的任务会重新提交生图请求。
7. 启动时清除旧版自动填入的内置共用要求，保留已单独保存的产品要求、模板绑定和自定义共用内容。没有单独保存要求的旧产品，如当前要求为空，请先填写或选择模板并保存，再发起分析。

相对 v0.2.10 新增任务状态和生图配置的一次性迁移，无需清空数据库或重新导入产品。完整步骤见 [Windows 更新说明](../windows-update.md)。
