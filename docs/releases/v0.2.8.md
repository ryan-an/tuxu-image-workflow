# 图序 v0.2.8 更新说明

版本日期：2026-11-03。

## 本次更新

- 没有产品实拍图时，生图传入该产品全部位置的对标图，重复图片只传一次，并标明每张附图所属位置、当前生成卡片及其对应编号。其他位置的图片用于参考整套风格、配色和产品信息。
- 当前卡片没有对标图时明确注明，结合其他参考图与提示词设计；有实拍图时继续只使用所选实拍视角。附图说明只加入实际生图请求，已保存的提示词原文保留。
- 兼容“场景1／场景 1”“A+(1)／A+ 1”等等价位置名称及全角符号，修复完整提示词因名称格式差异被判为无法对应图片位置的问题。实时预览和正式保存使用同一匹配规则，重复、缺失或无法识别的位置仍会提示错误。
- 单张分析的返回格式示例采用当前所选位置，避免生成其他卡片时示例仍指向尺寸图。
- 包含 v0.2.7 的保存校验与编号换行兼容改动：保存失败提示具体产品和字段，保留编号内部换行、制表符，下载时再转换为有效文件名。

## 升级说明

1. 保存网页上的编辑，等待正在生成的任务结束。仍有保存失败的草稿时先另行留存，更新工具只能备份已保存的数据。
2. 从图序窗口“更多”或托盘菜单选择“退出图序并停止服务”。关闭窗口只会隐藏到托盘。
3. 运行 `tuxu-update-windows-x64-v0.2.8.exe`，选择原程序目录后开始更新。保留原 `data/`、`.env` 和 `CREDENTIAL_SECRET`。
4. 更新完成后重新启动图序并刷新页面，在“账号菜单 → 更新日志”确认显示 **v0.2.8**。
5. 更新前已入队的任务可能缺少整套参考图快照，如需完整使用新生图规则，请停止旧任务后重新创建。此前因名称格式误判而失败的任务不会自动恢复或重新调用模型，原有提示词保留。

相对 v0.2.7 无新增数据库迁移，不需要清空数据库或重新导入产品。完整步骤见 [Windows 更新说明](../windows-update.md)。
