# 图序 v0.2.2 更新说明

日期：2026-10-27。本次汇总当前 Git 工作区相对已有提交的改动，生成 Windows x64 修订版部署与离线更新包；不包含个人配置、业务数据库和素材，不执行 Git 提交或服务器部署。

## 本次更新

- Windows 启动器、更新器改为与平台一致的浅色窗口，使用开源 AntdUI、图序图标和平台设计变量；启动、停止及更新不弹命令行窗口。
- 启动窗口显示运行状态、本机与局域网地址，支持打开工作台、复制地址、查看日志、打开数据目录及允许局域网访问；首次启动提供可显示和复制的随机管理员密码。
- 更新工具选择原程序目录后检查、备份并替换程序，保留 data 和 .env；拒绝运行中更新及降级，程序替换失败时尝试恢复旧文件。
- 提示词分析、生图提交和结果查询取消应用内固定并发名额；平台限流按工作区、凭据版本、平台和模型隔离，避免其他工作区或更换后的 Key 被连带暂停。图片处理和数据库资源保护保留。
- 队列和图片工作台隐藏分析耗时明细，继续显示任务状态和进度；移除不再生效的并发设置。
- 表格「保存并解析」先保存完整新产品、十个图片位置及表格数据，成功后再显示到工作台；失败时保留解析窗口与草稿。
- 产品编号支持空格、星号和斜杠等业务字符；下载时转换为文件名，并分别保存转换后同名的产品目录，避免相互覆盖。
- 补充 Windows 部署、Docker 数据导出、备份迁移与失败恢复说明，并增加对应验证。

## 更新方法与配置变化

1. 保存编辑并等待任务结束，在图序窗口「更多」或托盘菜单选择「退出图序并停止服务」。旧版有退出按钮时点击退出；叉掉新版窗口只会隐藏到托盘。
2. 运行 `tuxu-update-windows-x64-v0.2.2.exe`，选择原图序程序目录，点击「开始更新」。
3. 工具自动备份至 `data/backups/`，保留原 data、.env 与加密主密钥；显示完成后从原目录启动图序，再刷新浏览器。

不要重新生成或更换原 `CREDENTIAL_SECRET`。首次部署或从 Docker 迁移使用完整 ZIP，先按[数据迁移指南](../data-migration.md)导出并整理原数据。

首次启动会追加执行 `016.sql`，清理缺少工作区和凭据归属的旧全局限流记录，保留任务自身的重试时间、账号、图片和历史数据。旧的 `PROMPT_CONCURRENCY_LIMIT`、`IMAGE_SUBMIT_CONCURRENCY_LIMIT`、`IMAGE_QUERY_CONCURRENCY_LIMIT` 不再生效；`EXECUTION_PROFILE` 只影响图片预处理。平台自身的限流仍然适用。

新版启动后需要回退时，先停止服务并另存当前数据，再恢复升级前的完整程序、data 和 .env；不要混合不同快照的 SQLite、WAL 和 SHM 文件。详细步骤见 [Windows 更新说明](../windows-update.md)。
