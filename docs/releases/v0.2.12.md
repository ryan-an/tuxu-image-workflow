# 图序 v0.2.12 更新说明

版本日期：2026-11-10。

- 生图结果暂不存在时，使用已保存的任务 ID 退避重查最多 5 次，不立即失败，不自动重复提交生图。
- 持续查不到结果时，点击重新生成创建新任务，保留原平台 ID、错误和历史记录。
- 普通查询或下载失败继续沿用原 ID，查询恢复正常后清除旧错误。

升级前保存编辑并等待任务结束，从托盘退出并停止服务，运行 tuxu-update-windows-x64-v0.2.12.exe，选择原程序目录。完成后重启并刷新页面。保留 data、.env 和 CREDENTIAL_SECRET。相对 v0.2.11 无新增数据库迁移。
