# 图序 v0.2.6 更新说明

版本日期：2026-11-02。本次从 v0.2.4 递增两个补丁号，统一通过 v0.2.6 Windows 更新包提供；v0.2.5 为中间准备记录。

## 本次更新

- 提示词各部分均使用 AI 返回内容，不再用整套模板原文替换或补齐产品要求与图片尺寸。
- 产品实拍图可留空，提示词生成、生图及表格解析保存均不要求实拍图必填。没有实拍图时，生图使用当前卡片的参考图并注明为参考图；有实拍图时继续使用所选实拍视角。
- 实拍上传窗口补充误传风险及照片建议，强调“没有产品实拍图就留空，请勿用参考图代替”；工作台外部提示位于整条资料栏下方、图片筛选栏上方，横跨整行。
- 下载图片在原名称前增加位置序号，按每套图片的顺序编号；仅下载部分图片时保留原位置序号。
- 保存并解析窗口仅展示待新增、待更新或需要补齐表格结构的产品，无待保存内容时显示“无需更新”。
- 包含 v0.2.4 的 Windows 更新许可目录检查、旧数据库换行校验兼容及构建残留清理修复。

## 升级说明

1. 保存编辑并等待任务结束，从图序窗口“更多”或托盘菜单选择“退出图序并停止服务”。
2. 运行 `tuxu-update-windows-x64-v0.2.6.exe`，选择原程序目录后开始更新。
3. 保留原 `data/`、`.env` 和 `CREDENTIAL_SECRET`。不要删除数据库或手动修改迁移记录。
4. 完成后重新启动图序并刷新浏览器，确认显示 **v0.2.6**。旧提示词保持不变，重新分析后采用新的提示词规则。

相对 v0.2.4 无新增数据库迁移；从更早版本升级时，启动程序会执行尚未应用的迁移。更新工具会备份数据与配置，成功快照合计保留最近 2 份，重要备份请另存到其他设备。完整步骤见 [Windows 更新说明](../windows-update.md)。
