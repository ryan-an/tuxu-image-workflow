# 图序 v0.2.3 更新说明

发布日期：2026-10-27。

## 本次更新

- 编辑者也可进入设置并保存模型、节点、图片比例、分辨率等生成配置。
- 编辑者界面隐藏 API Key 输入、清除操作和配置状态；服务端继续限制只有工作区所有者能够修改或清除密钥，查看者不能修改设置。
- 豆包助手需要修复密钥时，向编辑者提示联系所有者；编辑者仍可调整对话模型。
- Windows 服务窗口采用精简布局，关闭或最小化后隐藏到通知区域，后台任务和局域网访问继续运行；重复打开同一程序目录的 EXE 会唤回窗口。
- Windows 窗口及托盘默认使用局域网地址打开工作台，没有可用地址时回退到本机地址。
- 更新工具采用大窗口布局，新增「备份数据」按钮，可单独备份数据与原配置，无需安装更新。
- 手动备份与自动更新备份合计保留最近 2 份成功快照，新操作成功后才清理更早的成功备份；失败、恢复未完成或无法识别的备份不自动删除。
- Windows 包根目录不再展示「第三方许可」文件夹，组件声明统一收进 runtime/licenses，仅适用于第三方组件。
- 新增 `npm run windows:pack:update`，构建后仅生成离线更新工具和校验文件，沿用当前版本号。

## 升级说明

1. 保存编辑并等待任务结束，从图序窗口「更多」或托盘菜单选择「退出图序并停止服务」。关闭窗口只会隐藏到托盘。
2. 运行 v0.2.3 更新工具并选择原程序目录；保留原 data、.env 与 `CREDENTIAL_SECRET`。
3. 更新完成后从原目录启动图序，刷新浏览器以使用新的设置权限。

手动备份不包含程序文件。重要快照请另存到其他设备，避免被后续备份清理；暂不开放客户自助恢复入口，需要恢复时联系维护者。

相对 v0.2.2 无新增数据库迁移。更早版本的配置和数据升级要求见 [v0.2.2 更新说明](v0.2.2.md)；更新与备份用法见 [Windows 更新说明](../windows-update.md)。
