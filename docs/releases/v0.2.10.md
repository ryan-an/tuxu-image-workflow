# 图序 v0.2.10 更新说明

版本日期：2026-11-06。

## 本次更新

- 豆包对话与提示词分析默认使用 `doubao-seed-2-1-pro-260915`。已有工作区在首次启动新版时也会统一初始化一次，包括原先填写的其他模型或 Endpoint ID；完成后仍可由所有者选择其他模型，之后重启保留新选择。
- 模型配置窗口隐藏“运行方式”和“Grsai 生图节点”，保存其他配置时保留原有值。
- 单张与整套分析由模型直接编写完整提示词，保留用户指定的结构、顺序和原文；增加通用执行与排版要求，并关闭豆包深度思考。已保存的提示词继续保留。
- 提示词预览支持 Markdown 标题、列表、加粗、表格和代码块，流式正文收到后及时显示；保留正在手动编辑的草稿。
- 新上传的实拍图、参考图及表格导入图片大于 6MB 时自动压缩至 6MB 以下，保留比例和透明背景；已有素材不主动重新压缩。
- GPT 生图尺寸按比例分组提供下拉预设，按型号显示适用尺寸，并保留已保存的自定义尺寸。
- 生图任务操作后读取最新状态，卡片显示尚未结束的任务、提交成员和平台进度，中断任务提供继续查询、恢复或核对入口。

## 升级说明

1. 保存网页上的编辑，等待正在生成的任务结束。尚未保存的草稿请先另行留存。
2. 从图序窗口“更多”或托盘菜单选择“退出图序并停止服务”。关闭窗口只会隐藏到托盘。
3. 运行 `tuxu-update-windows-x64-v0.2.10.exe`，选择原程序目录后开始更新。保留原 `data/`、`.env` 和 `CREDENTIAL_SECRET`。
4. 更新完成后重新启动图序并刷新页面，在“账号菜单 → 更新日志”确认显示 **v0.2.10**。
5. 首次启动会执行新增的一次性模型配置迁移，将所有已有工作区（含归档工作区）的豆包模型设为 `doubao-seed-2-1-pro-260915`。请在火山方舟开通该模型服务；如需其他模型，可在升级后由所有者重新选择。
6. 原有产品、提示词、图片、密钥、个人生图参数及已排队任务配置保留。已有任务沿用入队时的配置；需要使用新模型或新提示词规则时，请在升级后重新发起分析。

相对 v0.2.9 新增一次性模型配置迁移，无需清空数据库或重新导入产品。完整步骤见 [Windows 更新说明](../windows-update.md)。
