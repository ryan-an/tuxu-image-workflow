# 图序 v0.2.7 更新说明

版本日期：2026-11-03。

## 本次更新

- 取消产品编号内部换行、制表符等控制字符的拒绝规则，表格解析与产品保存允许保留这些内容；下载时转换为有效文件名，不改写已保存的产品编号。
- 保存校验失败时，提示具体产品及名称、编号、生成要求或图片位置的问题，便于修改后重试。
- 产品表单提前提示全为空格的名称，避免提交后才发现保存失败。
- 补充保存校验的诊断信息，不记录产品资料、提示词和图片正文。
- 实拍图继续允许留空；没有实拍图时使用当前卡片的参考图，并注明为参考图。

## 升级说明

1. 如果页面仍显示保存失败，先将尚未保存的修改另行留存，不要直接刷新出错页面。更新工具备份的是已保存到服务器的数据。
2. 等待正在生成的任务结束，从图序窗口“更多”或托盘菜单选择“退出图序并停止服务”。
3. 运行 `tuxu-update-windows-x64-v0.2.7.exe`，选择原程序目录后开始更新。保留原 `data/`、`.env` 和 `CREDENTIAL_SECRET`。
4. 重新启动图序。原出错页面如仍保留草稿，先点击“重试保存”，根据具体提示修正数据；确认保存成功后再刷新页面，加载新版前端。
5. 在“账号菜单 → 更新日志”确认显示 **v0.2.7**。

相对 v0.2.6 无新增数据库迁移，不需要清空数据库或重新导入产品。完整步骤见 [Windows 更新说明](../windows-update.md)。
