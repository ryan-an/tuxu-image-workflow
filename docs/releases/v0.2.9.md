# 图序 v0.2.9 更新说明

版本日期：2026-11-04。

## 本次更新

- 有产品实拍图时，单张、整套及重新生图的每次请求均附带该产品全部实拍图，重复图片只传一次，不再按分析结果或历史视角编号筛选。没有实拍图时继续使用该产品整套对标图，并标明当前生成位置。
- 自定义模板的选择与正文一起保存到当前产品，再次打开、刷新或切换产品后恢复各自的选择；正文与默认要求相同的自定义模板也独立保存。模板更新或删除不会覆盖产品已保存的正文。
- 未保存的草稿同时保留模板选择，撤销套用及恢复已保存内容时同步恢复选择。套用模板或保存模板后，仍需点击保存当前产品要求才会用于生成。
- 整套提示词要求为空或只有空白时显示明确提示；当前有效要求为空时，引导填写或选择模板并保存后再分析生成提示词。
- 要求标签显示“使用模板：模板名称”，移除下方重复的来源说明；长名称省略显示，悬停可查看完整名称。

## 升级说明

1. 保存网页上的编辑，等待正在生成的任务结束。尚未保存的草稿请先另行留存，更新工具只能备份已保存的数据。
2. 从图序窗口“更多”或托盘菜单选择“退出图序并停止服务”。关闭窗口只会隐藏到托盘。
3. 运行 `tuxu-update-windows-x64-v0.2.9.exe`，选择原程序目录后开始更新。保留原 `data/`、`.env` 和 `CREDENTIAL_SECRET`。
4. 更新完成后重新启动图序并刷新页面，在“账号菜单 → 更新日志”确认显示 **v0.2.9**。
5. 更新前已排队或失败的生图任务可能保留原先筛选的附图。如需使用全部实拍图，请取消旧任务后重新创建；任务入队后新增的照片也需新建任务才会附带。
6. 旧产品的自定义正文保留；此前未记录模板来源的产品，可重新选择模板并保存一次，以建立关联。

相对 v0.2.8 无新增数据库迁移，无需清空数据库或重新导入产品。完整步骤见 [Windows 更新说明](../windows-update.md)。
